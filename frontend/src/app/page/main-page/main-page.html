Le labo

Ce que j'explore pour la suite.

Le web change vite. Voilà les sujets sur lesquels je passe mes soirées — pas pour suivre une mode, mais pour construire des choses plus utiles, plus vite.

Module 01 · Prototype

Des agents qui codent avec moi

Avec Prism Atlas, je teste comment un agent peut analyser un projet, proposer des modifications et vérifier son travail — en gardant l'humain aux commandes.

Module 02 · En pratique

L'automatisation partout où c'est utile

Tests, builds, déploiements : tout ce qui est répétitif devrait se faire tout seul. CI/CD et GitHub Actions sont devenus mes réflexes.

Module 03 · À creuser

Des interfaces qui s'adaptent

Animations légères, accessibilité, performance : je cherche des interfaces vivantes mais rapides, qui restent agréables sur n'importe quel appareil.

Ma façon de travailler

Comprendre, construire, améliorer.

J'apprends en réalisant de vrais projets, en reliant l'interface, la logique métier et les données. Ce qui compte pour moi : que ce soit utile à ceux qui s'en servent.

  1. 1

    J'écoute

    Objectifs, usages, contraintes : je pose les bonnes questions avant de choisir la technique.

  2. 2

    Je construis

    Du code propre, testé, et des écrans cohérents. Je montre vite pour avoir des retours tôt.

  3. 3

    J'améliore

    Chaque retour fait évoluer le produit. Un site n'est jamais vraiment « fini ».
